# Math Quest

A math game for kids: solve problems to power up a buddy, beat bosses and raids, collect cards, and duel friends.

- Play: deploy `worker.js` with Wrangler (`npx wrangler deploy`) or paste it into a Cloudflare Worker.
- Optional online accounts and duels: create the KV namespace described in `wrangler.toml`.
- Develop: edit `src/`, run `npm install`, `npm test`. Rules and layout are in [CLAUDE.md](CLAUDE.md).
